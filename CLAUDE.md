Projet : plateforme de recrutement full-stack

Frontend :
- Angular
- TypeScript

Backend :
- Python
- FastAPI

Fonctionnalités :
- Gestion des candidats
- Gestion des offres d'emploi
- Upload CV
- Parsing CV
- Extraction des compétences
- Scoring des CV
- Matching candidat/offre
- Prédiction de salaire
- Assistant de négociation salariale

Architecture :
- Frontend Angular
- API REST FastAPI
- Services Python séparés
- PostgreSQL
- Module IA/ML séparé

Règles :
- Ne pas modifier des fichiers sans analyser l'existant
- Réutiliser les composants/services existants
- Ne pas dupliquer du code
- Respecter l'architecture actuelle
- Utiliser du code Python typé
- Utiliser Pydantic pour les schemas API
- Tester les fonctionnalités importantes
- Ne jamais exposer les données personnelles des CV dans les logs
